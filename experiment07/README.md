# Experiment 07 - PHP Learning Exercises

Complete set of PHP beginner exercises from the official PHP course.

## Exercises Included

### 1. Exercise 2: Built-in PHP Server
- Learn to run PHP without XAMPP
- Use the built-in development server
- File: `built_in_server.php`

### 2. Exercise 3: PHP Basics
- Variables and output methods
- Data types verification
- Associative arrays
- File: `profile.php`

### 3. PHP Constants
- Define custom constants
- Use PHP built-in constants
- File: `constants.php`

### 4. Data Types
- All PHP data types (String, Integer, Float, Boolean, Null, Array)
- Type checking functions
- File: `data_types.php`

### 5. Challenge: System Information Page
- Display system and PHP information
- Use $_SERVER superglobal
- Implement foreach loops
- File: `sysinfo.php`

## How to Run

### Using XAMPP:
1. Copy `experiment07` folder to `C:\xampp\htdocs\`
2. Start Apache in XAMPP Control Panel
3. Open: `http://localhost/experiment07/`

### Using Built-in Server:
1. Open Terminal/Command Prompt
2. Navigate to experiment07 folder
3. Run: `php -S localhost:8000`
4. Open: `http://localhost:8000`

## Files

- `index.php` - Main exercise menu
